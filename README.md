# Calculator
A simple command-line calculator written in C.
## Operations
The calculator supports:
- addition
- subtraction
- multiplication
- division
## Build
Compile the program with:
```bash
gcc main.c add_sub.c mul_div.c utils.c -o calculator
gcc main.c add_sub.c mul_div.c utils.c -o calculator
```

## Run

```bash
./calculator
```
